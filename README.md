# 🚗 Assistant & Commute Bot (Waze + Google Maps + Нагадування)

Персональний київський Telegram-бот у чаті [@Onmaywayyyy_bot](https://t.me/Onmaywayyyy_bot):
1. **Затори Waze у реальному часі:**
   - Будні о **07:00**: з дому (**вул. Юлії Здановської, 36**) на роботу (**вул. Олександра Кониського, 15**).
   - Будні о **17:45**: з роботи додому.
   - У будь-який момент дня: кнопка **«🚗 Затори зараз»**.
2. **Розумні нагадування людською мовою:**
   - Розуміє живу українську мову:
     - *«Нагадай поміняти гуму в п'ятницю о 14:00»*
     - *«Нагадай випити ліки через 40 хв»*
     - *«Нагадай завтра о 10:30 подзвонити лікарю»*
     - *«через півгодини вимкнути духовку»*
     - *«Нагадай о 20:00 забрати посилку»*
     - *«Нагадай через 15 секунд перевірити таймер»*
   - Зберігає всі нагадування в базу даних SQLite (`reminders.db`), тому вони не губляться навіть після перезапуску бота.
   - Повідомлення приходить точно в призначений час зі звуком і сповіщенням.

---

## 📱 Керування ботом у Telegram:

* **Звичайний текст:** просто напишіть будь-яку фразу з часом або днем тижня.
* **Кнопки швидкого доступу:**
  * `🚗 Затори зараз` — оцінити дорогу на цей момент
  * `📋 Мої нагадування` — список усіх активних завдань
  * `🌅 На роботу` / `🌇 Додому` — швидкий прорахунок конкретного напрямку
* **Команди:**
  * `/list` — переглянути всі заплановані нагадування
  * `/del <номер>` — скасувати нагадування за номером
